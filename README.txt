IPHONE DEPLOYMENT

Upload the HTML file and the contacts folder together. Do not upload only the HTML.

On iPhone Safari:
1. Open a verified WhatsApp lead.
2. Tap Save Contact on iPhone.
3. Tap Create New Contact.
4. Tap Done.
5. Return to the dashboard and tap Open WhatsApp.

iOS requires the user to confirm and save each contact. A website cannot silently write to Contacts.
